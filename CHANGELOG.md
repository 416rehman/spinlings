# Changelog

One entry per release (SPEC 32), newest first. Each says what changed in plain words, any compatibility impact, and any change to what the mod sends, what the server stores or what other players can see. The mod and the server share one version; the server is deployed first.

## 0.1.0 (unreleased)

The first release: Spinlings season 1, the mod and the server.

- **The game:** wild encounters while Claude works, duels with other players' teams and Rivals, packs charged by presence, three evolution stages and raised forms, foil, Mythics, fusion, crafting, the Wandering Trader, trading, gifts, drops, streaks, leagues and the daily rules.
- **Two worlds:** online by default (anonymous, no sign-up) and an offline world that sends nothing; optional passkeys to play on another computer; community servers.
- **What the mod sends, what the server keeps and what others see:** as described in PRIVACY.md at this release.
- **Compatibility:** API `/v1`, rules version 1, generator version 2. `minClient` is 0.1.0.
